### AVG

```TEXT
SELECT year_month, AVG(rental_count) AS avg_rental_count
FROM (
    SELECT
        strftime('%Y-%m', rental_date) AS year_month,
        book_id,
        COUNT(*) AS rental_count
    FROM rental
    GROUP BY
        strftime('%Y-%m', rental_date),
        book_id
)
GROUP BY year_month
ORDER BY year_month;
```
